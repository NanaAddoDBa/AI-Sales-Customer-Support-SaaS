# Agents ownership

Owns bounded reasoning/tool orchestration and evaluations. Currently implemented: a fail-closed tool policy classification. No model connection, tool execution or automatic messages are enabled.

Public FAQ answers require approved retrieved evidence. Prices/stock require live commerce data. An order number or claimed email address is not proof of ownership. Checkout requires explicit shopper intent and a validated merchant URL. Refund/cancel/address/discount actions require staff approval and remain absent from executable tool contracts. Unknown tools are denied.

The eventual runtime must validate tool parameters, derive tenant/customer identity independently of the model, satisfy the policy requirement, reserve spend, bound iterations and recheck human control before delivery. Never equate `toolRequirement` with permission to execute.
